# Bismuth - Privacy Policy

Bismuth only accesses its own files or system files necessary for running the app without notifying the user.



When importing files (image, PDF, Bismuth file), Bismuth only copies files that have been selected by the user to a temporary folder for processing and then, when saving the notebook, copies them to the notebook folder. Said temporary folder is managed and cleared by the Windows operating system and/or Bismuth itself.

After imported files have been saved to the notebook, they will no longer be processed, but rather only accessed in order to display notebook contents properly.



No other file or any personal information is accessed, collected or leaves your device. All processing happens on-device.
