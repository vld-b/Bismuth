# Installation instructions:
## For Microsoft store, see above
## For manual installation
1. Download (latest) zip from releases page and unzip it
2. Right click the .cer file in the unzipped folder and open it with crypto shell extensions
3. Choose install certificate, then choose "Local Machine", press next and grant administrator rights
4. Choose "Place all certificates in the following store", click Browser and choose "Trusted Root and Certification Authorities"
5. 
<img src="./Screenshot 2026-09-15 171319.png" /> 

1. Click "Ok", then "Next" and finally "Finish"
2. The certificate installer should exit. Now, install the .msix package normally.
